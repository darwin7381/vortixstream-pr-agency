## CRITICAL Tailwind v4 GOTCHA
`font-[var(--font-display)]` arbitrary class does NOT apply font-family in Tailwind v4.
Must use either:
- Inline style: `style={{ fontFamily: "var(--font-fraunces), Georgia, serif" }}`
- Or named utility class generated by `@theme inline { --font-display: var(--font-fraunces) }`

All headings should use the helper classes `.t-display / .t-h2 / .t-h3 / .t-lead / .t-body / .t-quote / .t-num-display / .t-caption` defined in `src/app/globals.css`. These set font-family + size + line-height + tracking in ONE place.
